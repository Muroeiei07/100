# 王清越 - 亮麗極簡個人網頁 (Vibrant Minimalist Portfolio)

這是為您量身打造的**「單一檔案」亮麗風格個人網頁**。
採用了現代化的 **Glassmorphism (毛玻璃)** 設計風格、明亮溫暖的漸層色彩，並將內容進行了**高度精簡**，讓您的目標與專業一眼就能被看見。同時預留了**生活照**的專屬展示空間。

## 🌟 本次優化亮點
1. **單一檔案 (Single-File)**: HTML、CSS、JavaScript 全部整合在 `index.html` 中，超級乾淨、無需管理多個檔案，點擊即可開啟。
2. **亮麗風格 (Vibrant Style)**: 捨棄沈重的暗色系，採用乾淨白底搭配紅/粉/橘的溫暖漸層，背景還有緩慢飄動的色彩點綴。
3. **精簡內容 (Streamlined Content)**: 摒棄過多文字，將「學習代碼」與「開發遊戲」提煉為精緻的圖文卡片，更具專業與設計感。
4. **生活照畫廊 (Life Gallery)**: 特別設計了 1:1 正方形網格的照片牆，滑鼠游標移過去時會有漂亮的放大與色彩遮罩效果。

## 📁 檔案說明
* `index.html`: 您的專屬個人網頁 (包含所有代碼與樣式)。
* `README.md`: 本說明文件。

## 📸 圖片替換教學
請將您的照片與 `index.html` 放在**同一個資料夾**內，並依照以下檔名命名：
* **大頭貼**: 命名為 `profile.jpg`
* **生活照 1**: 命名為 `life1.jpg`
* **生活照 2**: 命名為 `life2.jpg`
* **生活照 3**: 命名為 `life3.jpg`

*(註：若暫時沒有放入照片，網頁會自動顯示粉色系的佔位圖片，不會破版！)*

## 🚀 部署指南 (上傳到網路上)
1. 前往 [Vercel](https://vercel.com/) 註冊/登入。
2. 點擊 "Add New Project"。
3. 將包含 `index.html` 與您照片的資料夾，直接拖曳到網頁上即可完成部署，獲得免費網址！
